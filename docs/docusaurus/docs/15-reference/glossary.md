# Glossary

| Term | Meaning |
|---|---|
| **Abilities** | Scopes on an API key such as `workflows:read` |
| **Action (agent)** | A tool call awaiting or having received a verdict |
| **Agent** | A conversational AI with instructions, a model and tools |
| **Artifact** | A stored file produced or consumed by runs and agents |
| **Assistant** | A personal AI, separate from shared agents |
| **Autonomy mode** | How freely an agent may act |
| **Binding (tool)** | A tool attached to an agent with fixed and exposed fields |
| **BYOK** | Bring your own key for an AI provider |
| **Connector** | Definition of an integration |
| **Connection** | Your authorized account for a connector |
| **Credit** | Unit of metered usage |
| **Edge** | Link between two node ports |
| **Fan-out** | Running a node once per item of a list |
| **Interface** | The inputs and outputs of a workflow |
| **Knowledge collection** | A group of embedded documents |
| **Node** | A single step in a workflow |
| **Node run** | One execution of a node within a run |
| **Overage** | Spending beyond the credit balance, billed later |
| **Page** | A shareable web UI wrapping a workflow |
| **Polling** | Periodically asking an app for new data |
| **Publish** | Create an immutable workflow version |
| **Reflection** | Suggested improvements derived from past sessions |
| **Run** | One execution of a workflow |
| **Secret** | An encrypted named value |
| **Session** | One conversation with an agent or assistant |
| **Skill** | A reusable bundle of instructions and references |
| **Sub-workflow** | A workflow called as a node in another |
| **Trigger** | What starts a run automatically |
| **Watch** | A webhook subscription registered with an app |
| **Workspace** | The tenant that owns data, members and billing |
