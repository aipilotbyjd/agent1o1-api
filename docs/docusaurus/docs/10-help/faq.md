# FAQ

## What's the difference between a playbook and an agent?

A playbook follows steps you set, the same way each time. An agent decides its own steps to reach a goal. You can combine them by giving an agent a playbook as an ability.

## What's the difference between an agent and the Assistant?

Agents are built and shared by your team. The Assistant is your own private AI with briefings, an inbox and chat channels.

## Do I need to write code?

No. You build with steps on a canvas, and the AI builder can set things up from a description. The API is optional.

## Are my passwords and keys safe?

Connections, Vault secrets and AI keys are encrypted, and values are never shown again after you save them. They're hidden in run history.

## Will the AI send emails or change things without asking?

Only if you allow it. Agents and the Assistant follow the autonomy setting you choose, and admins can set a limit for the whole workspace. Smart Inbox creates drafts and never sends them.

## What happens when I run out of credits?

Runs stop cleanly and you're told. Add credits, upgrade or turn on overage, then retry. See [Credits](../08-billing/credits.md).

## Can I use my own AI account?

Yes. Add your key in **Settings → AI providers**.

## Can I undo a deleted playbook?

Yes, from **Trash**, until you delete it permanently.

## Can other people use my playbooks without an account?

Yes, through a [Page](../07-pages-and-files/pages.md). Remember each use costs your credits, so add a password if it shouldn't be open.

## Can I go back to an earlier version?

Yes. Playbooks and agents keep a version history.

## Which apps can I connect?

More than 60. See [Steps you can use](../03-playbooks/steps.md#app-steps).

## How do I cancel?

**Settings → Billing → Plans**. Your plan runs until the end of the period you've paid for.
