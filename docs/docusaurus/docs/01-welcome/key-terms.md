# Key terms

| Term | What it means |
|---|---|
| **Workspace** | Your team's space. Playbooks, agents, apps, members and billing all belong to a workspace. You can belong to several. |
| **Playbook** | A set of connected steps that runs the same way each time. |
| **Step** | One action in a playbook: ask AI, send an email, add a row, wait for approval. Also called a node. |
| **Run** | One execution of a playbook. |
| **Trail** | The history of every run in your workspace. |
| **Trigger** | What starts a playbook automatically: a schedule, a web request, or something happening in an app. |
| **Agent** | An AI you give instructions and abilities. It decides which steps to take to reach a goal. |
| **Assistant** | Your personal AI, separate from team agents. |
| **Skill** | A reusable guide (instructions and reference files) an agent can use when relevant. |
| **Knowledge** | Documents an agent or playbook can search to answer questions. |
| **Apps** | Your connected accounts (Slack, Gmail, Notion, and others). |
| **Vault** | Safe storage for passwords, tokens and keys. |
| **Blueprint** | A ready-made playbook, agent or page you can copy and adapt. |
| **Page** | A simple web page or form that runs a playbook for visitors. |
| **Artifact** | A file created or used by your playbooks and agents, such as a PDF or a spreadsheet. |
| **Approval** | A pause where a person must say yes or no before something continues. |
| **Credits** | The unit that measures how much you use. |
