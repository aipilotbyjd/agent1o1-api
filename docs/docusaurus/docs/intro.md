# Welcome to Agent1o1

Agent1o1 lets you automate work with AI, without writing code. You connect the apps you already use, describe what should happen, and Agent1o1 does it, every time.

## What you can build

| Build this | When you want to |
|---|---|
| **Playbook** | Run the same steps every time: "When a form is submitted, summarize it with AI, add a row to Google Sheets, and post to Slack." |
| **Agent** | Give an AI a goal and tools, and let it decide the steps: "Handle incoming support questions using our help docs." |
| **Assistant** | Get a personal AI for your own day: daily briefings, meeting prep, and a smart inbox. |
| **Page** | Share a playbook as a simple web page or form that anyone can use. |

## Find your way around

The left sidebar groups everything:

- **Build**: Playbooks, Agents, Pages, Blueprints
- **Connect**: Apps, Knowledge, Skills, Vault
- **Monitor**: Approvals, Trail, Artifacts
- **Trash**: restore anything you deleted

Settings (account, team, billing, API keys) are under your profile menu.
