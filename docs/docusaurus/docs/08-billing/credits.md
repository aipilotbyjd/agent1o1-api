# Credits and usage

Credits measure how much you use Agent1o1.

## What uses credits

- Each playbook run uses a small base amount.
- AI steps, agent conversations, knowledge and speech use more, depending on the model and how much text is involved.
- Some app steps have a fixed cost.

You can see the cost of any run, step by step, in the [Trail](../03-playbooks/runs-and-trail.md).

## Where credits come from

| Source | Notes |
|---|---|
| Your plan | A monthly amount that resets each billing period |
| Free trial | Extra credits when a trial starts |
| Credit packs | One-time top-ups that don't reset each month |
| Referrals | Earned when people you refer join |
| Gifts from us | Occasional grants |

## Check your balance

**Settings → Billing → Credits** shows your balance, and **Usage** shows where credits are going: which playbooks, agents and models use the most.

## Running low

Set a warning (for example at 75% and 90%) in your billing settings, and we'll tell you.

- **Buy a credit pack** for an instant top-up.
- **Upgrade** to a plan with more.
- **Turn on overage** to keep running past zero. Extra use is billed on your next invoice.

## When credits run out

Runs stop cleanly and the workspace owner is notified. Add credits and retry the failed runs from the Trail.

## Limits that protect you

- Each run has a **maximum credit amount**, so a loop that goes wrong can't empty your balance.
- Each plan has daily and weekly **AI spending limits**.
- Use your **own AI key** to pay your provider directly instead. See [AI providers](../06-apps-and-keys/ai-providers.md).

## Tips to use fewer credits

- Use smaller models for easy tasks.
- Filter early, so expensive steps run less often.
- Test with a few items before you run on a whole list.
