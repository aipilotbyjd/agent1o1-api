# Steps you can use

Steps are grouped in the library. Search by name or by app.

## AI steps

| Step | Use it to |
|---|---|
| **Ask AI** | Send any prompt to an AI model |
| **AI Answer** | Answer a question using the text you give it |
| **AI Extract** | Pull specific details (name, date, amount) out of messy text |
| **AI Classify** | Put text into one of your categories |
| **AI Score** | Rate something against your own scale |
| **AI Sentiment** | Tell if text is positive, negative or neutral |
| **AI Summarize** | Shorten long text |
| **AI Rewrite** | Change tone or format |
| **AI Translate** | Translate between languages |
| **AI Compare** | Compare two pieces of content |
| **AI Moderate** | Flag unsafe content |
| **AI Read File** | Read a PDF or an image and answer questions about it |
| **AI Image** | Generate an image |
| **AI Speech** / **AI Transcribe** | Turn text into speech, or speech into text |
| **Agent** | Run one of your [agents](../04-agents/overview.md) as a step |
| **Knowledge Search** / **Knowledge Save** | Search or add to your [knowledge](../04-agents/knowledge.md) |

Pick the model for each AI step. Faster models cost fewer credits, larger ones handle harder tasks. See [AI providers](../06-apps-and-keys/ai-providers.md) to use your own keys.

## Data steps

| Step | Use it to |
|---|---|
| **Call API** | Talk to any web service |
| **Transform**, **JSON**, **Array**, **String**, **Math**, **Date and Time** | Reshape and calculate |
| **Table**, **CSV Parse**, **Lookup** | Work with rows and columns |
| **Set Variable**, **Data Store** | Remember values, even between runs |
| **Web Scrape**, **Page to Markdown**, **HTML to Text**, **RSS Read** | Get content from the web |
| **PDF Create** | Make a PDF file |
| **PII Redact** | Hide personal details such as emails and phone numbers |

## Logic steps

Filters, routers, loops, waits and approvals. See [Control the flow](./flow-control.md).

## App steps

Steps for the apps you connect:

- **Google**: Gmail, Drive, Docs, Sheets, Slides, Calendar, Contacts, Forms, Tasks, Maps, Analytics, Search Console, YouTube
- **Microsoft**: Outlook, Teams
- **Messaging**: Slack, Discord, Telegram, Twilio (SMS, WhatsApp, calls), Zoom
- **Email sending**: SendGrid, Mailgun, Postmark, Resend, Brevo, SMTP
- **Marketing**: Mailchimp, Kit, ActiveCampaign, Klaviyo, Typeform
- **CRM and sales**: HubSpot, Salesforce, Pipedrive, Zoho, Apollo, Hunter
- **Projects**: Jira, Linear, Asana, ClickUp, Monday, Trello, Notion, Airtable
- **Developer**: GitHub
- **Commerce**: Stripe, Shopify
- **Scheduling and signing**: Calendly, Cal.com, DocuSign, Dropbox Sign
- **Search**: Brave Search, Tavily

Each app step needs a connection. See [Connect an app](../06-apps-and-keys/apps.md). Don't see your app? Use **Call API**, or ask us to add it.
