# Artifacts and files

**Artifacts** are the files in your workspace: reports, PDFs, spreadsheets, images, and anything you upload.

## Where files come from

- Playbooks and agents create them, for example **PDF Create** or **AI Image**.
- You upload them. Open **Artifacts** and choose **Upload a file**. You can also **upload a new version** of a file.

## Work with files

Search by file name, preview, and **download**. Open a file's menu for more options, such as sharing.

## Share a file

Choose who can open each file:

- **Restricted**: only the people you add
- **Workspace**: everyone in the workspace
- **Anyone with the link**

Add people individually, and remove their access at any time.

## Use files in playbooks

Steps that read files, like **AI Read File**, accept artifacts, and steps that create files save them here.

## Keep what matters

Download files you need to keep long-term. Delete files you no longer need.
