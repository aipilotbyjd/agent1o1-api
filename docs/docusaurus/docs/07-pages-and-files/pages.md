# Pages

A **Page** puts a simple web page in front of a playbook. Visitors fill in a form, the playbook runs, and they see the result. They don't need an account.

**Examples:** a "summarise this document" tool, a lead qualification form, a quote calculator.

## Create a page

1. Open **Pages** in the sidebar and create a new page, or start from a [Blueprint](./blueprints.md).
2. Choose the playbook it runs.
3. Arrange the content. You can add headings, text, images, buttons, FAQs, testimonials, pricing tables, videos, steps and more.
4. Add the form pieces: **fields** for the playbook's inputs, a **submit** button, and an **output** area to show the result. A **status** block shows progress while it runs.
5. Preview, then publish.

## Who can open it

| Access | Who |
|---|---|
| **Workspace** | Signed-in members only |
| **Link** | Anyone with the link |
| **Password** | Anyone with the link and the password |

## Keep in mind

- Every submission runs your playbook and uses your credits. Use a password if the page shouldn't be open to everyone.
- Teammates can leave comments on a page while you build it.
- Public pages need the Starter plan or above. Removing Agent1o1 branding needs Pro.
