# Knowledge

**Knowledge** is your own content, stored so AI can search it by meaning rather than exact words. Ask "how do refunds work?" and it finds the right section even if the page says "returns".

## Add knowledge

Open **Knowledge** in the sidebar and choose **Add knowledge**. You can:

- Upload files
- Paste text
- Connect an app, such as Google Drive or Notion, or point it at web pages

For connected sources you choose **Add once**, or **Keep in sync** so changes are picked up automatically (about every 15 minutes). **Sync now** refreshes a source on demand.

## Keep it tidy

- Open a source to see its documents, and remove any you don't want.
- Mark content as **private** to keep it to yourself.
- Use **Test knowledge search** and ask a question to check the answers you get.

## Use it

- Give an agent a collection so it can look things up. It can **search** when it needs to, or have the collection **always included** in every conversation.
- Use the **Knowledge Search** and **Knowledge Save** steps in a [playbook](../03-playbooks/steps.md).

## Good practice

- Keep one topic per document and give documents clear titles.
- Remove old versions, so the AI doesn't find out-of-date answers.
- Test with real questions your customers ask.
