# Skills

A **skill** is a guide an agent can pull in when it is relevant, such as "how we write release notes" or "our brand voice".

## What is in a skill

- A **name** and a short description, so the agent knows when to use it
- The **instructions** (a file called SKILL.md)
- Optional **reference documents**
- Optional **scripts**

## Create a skill

Open **Skills** in the sidebar and choose **Create Skill**. Describe it, write the instructions, and add references.

## Import from GitHub

Choose **Import from GitHub** and paste a repository link to bring in an existing skill. You can fork it and customise it, and **publish to GitHub** to share changes back.

Skills that come from GitHub stay in sync. If both sides changed, you are asked to **resolve sync conflicts**. Use **Sync settings** to change the branch or folder.

## Give a skill to an agent

Open the agent and add the skill to its abilities. See [Give an agent abilities](./abilities.md).
