# Insights and testing

## Memory

An agent can remember facts between conversations, such as a customer's preferred language. Open the agent's memory to see what it has kept, and add, edit or delete items.

## Reflections

Agent1o1 can review past conversations and suggest improvements, such as better instructions or a new memory. Open the agent's **Insights** and look at its **reflections**. **Apply** a suggestion or **dismiss** it. You can choose when reflections are created, and whether they are applied for you.

## Conversation grades

Agent1o1 can grade conversations against criteria you set, so you can see where an agent struggles.

## Tests

Build a set of test questions with the answers you expect, then run them after every change.

1. Create a test suite for the agent.
2. Add cases: a question, and what a good answer contains or which ability it should use.
3. Run the suite and review which cases passed.
4. If a change made things worse, restore the previous version of the agent.

Include tricky cases, like questions the agent should refuse.
